# ATS Resume Matching Service

An MVP Applicant Tracking System (ATS) component designed to support hiring workflows for SFU student clubs. This project focuses on resume-to-job skill matching, backend processing workflows, and maintainable service architecture.

The system was built to help automate parts of the resume review process by comparing candidate resumes against job-required skills and generating lightweight compatibility metrics.

> Note: This repository is a simplified and stable version of the system intended for demonstration and discussion purposes. The production implementation has a different internal structure and additional infrastructure that are not included in this public sample.

---

# Features

- Resume-to-job skill matching
- Skill normalization and deduplication
- JSON-based parsing workflows
- Lightweight backend processing
- Rust service infrastructure
- Python-based matching utilities
- Dockerized setup for portability

# Project Purpose

This project was created as part of an MVP ATS platform currently being used by SFU student clubs for internal hiring workflows.

The goal of the project was to create a maintainable and practical system that could:
- process candidate data
- evaluate resume skill alignment
- support lightweight recruiting workflows
- remain easy to iterate on during active use
